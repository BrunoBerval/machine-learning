### 🖼️ Redução de Dimensionalidade
[![Acessar Repositório](https://img.shields.io/badge/🔗_Acessar_Repositório-000?style=for-the-badge&logo=github)](https://github.com/BrunoBerval/dio_project2)

**Tecnologias:** `Python` `PCA` `t-SNE` `Autoencoders`

- Autoencoders para compressão

### 📈 Métricas de Avaliação
[![Acessar Repositório](https://img.shields.io/badge/🔗_Acessar_Repositório-000?style=for-the-badge&logo=github)](https://github.com/BrunoBerval/dio_project3)

**Descrição:** Implementação e cálculo de métricas para avaliação de performance de modelos de machine learning.

**Tecnologias:** `Python` `Scikit-learn` `Matplotlib` `Seaborn`

**Principais Tópicos:**
- Métricas de classificação e regressão

- Matriz de confusão

### 🎯 Treinamento YOLO
[![Acessar Repositório](https://img.shields.io/badge/🔗_Acessar_Repositório-000?style=for-the-badge&logo=github)](https://github.com/BrunoBerval/dio_project4)

**Descrição:** Criação completa de base de dados anotada e treinamento da arquitetura YOLO para detecção de objetos.

**Tecnologias:** `Python` `YOLO` `OpenCV` `Darknet`

**Principais Tópicos:**
- Anotação de datasets
- Treinamento de YOLO do zero
- Avaliação de modelos de detecção

### 👤 Reconhecimento Facial
[![Acessar Repositório](https://img.shields.io/badge/🔗_Acessar_Repositório-000?style=for-the-badge&logo=github)](https://github.com/BrunoBerval/dio_project5)

### 💭 Sistema de Recomendação
